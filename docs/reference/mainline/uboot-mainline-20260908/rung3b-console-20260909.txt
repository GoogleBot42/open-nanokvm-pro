  READ IT LIKE THIS. On CMD18 the card is in state 5 (DATA) with
  DAT_LINE_ACTIVE and READ_TRANSFER_ACTIVE set and DAT[3:0] = 0x4 -- it is
  streaming, and the host never collects. That is the reverse of what #91
  records, and the difference is only that #91's CMD13 came after the
  controller reset, which is what puts the card back in TRAN.

  On the rare CMD17 failure the host side looks the same
  (READ_TRANSFER_ACTIVE still set, usually no error interrupt at all) but
  the card has already finished: state 4 (TRAN). One of the five raised
  int 00108000 = ERROR | DATA_TIMEOUT_ERR.
