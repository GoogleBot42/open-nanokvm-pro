Identical configuration WITH mem=512M reset itself at 337 s every time, so the
difference is the memory limit, not the watchdog plumbing. Every reserved-memory
node is inside the first 512 MB (atf 0x40040000, optee 0x44200000,
vendor-pstore 0x48000000, ramoops 0x480e0000, bringup-log 0x480e8000), so
whatever the kernel touched above 512 MB is not described in the DT. A hang that
also defeats WDT0 is the AXI-stall signature on this SoC.

  free -m on the flashed appliance: total 428 MB. It has been running on half
  its RAM.
